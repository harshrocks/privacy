Privacy Policy

Application: Instagram MCP • Effective Date: November 2, 2026

This Privacy Policy explains how Instagram MCP ("the Application", "we", "us", or "our") handles user information and data accessed via Meta Platforms, Inc. APIs, including the Instagram Graph API and Facebook Login for Business.

Architecture Overview: Instagram MCP is a locally hosted Model Context Protocol (MCP) server that runs directly on your computer or private server. We do not operate remote tracking servers, do not collect analytics on your usage, and never transmit your credentials or account data to third parties.

1. Data We Access and Process

When you configure and authenticate Instagram MCP using your Meta App credentials and access tokens, the application accesses data strictly necessary to fulfill commands initiated by you through your AI/MCP client. Depending on the permissions granted, this includes:

  • Account & Profile Information: Account ID (IG_USER_ID), username, display name, biography, profile picture URL, follower and following counts, media counts.
  • Media & Publishing: Media items, image and video URLs, post captions, permalinks, publishing status, and upload containers.
  • Comments & Engagement: Post comments, comment text, usernames of commenters, timestamp data, and nested comment replies.
  • Messages (Direct Messages): Incoming and outgoing direct message text and conversations, strictly when requested by you to read or send messages.
  • Insights & Metrics: Aggregated account metrics, post impressions, reach, profile views, and engagement statistics.
  • Hashtags: Public hashtag search results and top/recent public posts for specified hashtags.

2. How We Use the Data

All data retrieved from Meta's APIs is used exclusively to:

  • Execute the specific MCP tool actions commanded by the authenticated user (e.g., retrieving profile info, drafting or publishing posts, reading post comments, checking insights).
  • Format API responses into structured responses for your MCP client (such as Claude Desktop, Antigravity, or other client software).
  • Maintain required operational parameters during the active session.

3. Data Storage & Retention

  • Local Processing: All API communication takes place directly between your local machine and Meta's official Graph API endpoints (https://graph.facebook.com).
  • No Central Database: We do not operate an external database, cloud server, or central storage where your Instagram data or tokens are aggregated or stored.
  • Token Security: Meta Access Tokens (IG_ACCESS_TOKEN) and User IDs are stored solely in your local environment variables or your client's local configuration files. You retain complete custody of your credentials.
  • Retention: No Instagram data is retained after the execution of the requested tool call completes. Temporary session memory is cleared when the application or client process stops.

4. Data Sharing & Third Parties

We do not sell, rent, monetize, or share any user data or Meta account data with advertisers, data brokers, or third parties. Data is exchanged only with official Meta Graph API endpoints to provide the service requested by the user.

5. User Rights & Data Deletion

In compliance with Meta Platform policies, GDPR, and other relevant privacy regulations, you have full control over your data:

  • Revoke App Access: You can disconnect Instagram MCP at any time directly through Meta:
    1. Go to your Facebook account Settings & Privacy → Settings → Apps and Websites.
    2. Find Instagram MCP (or the associated Meta App name) and click Remove.
    3. Alternatively, on Instagram, go to Settings → Website permissions → Apps and websites and remove the app.
  • Delete Stored Credentials: Because tokens are stored locally on your device, deleting your local environment variables or removing the server configuration from your MCP client immediately purges all access.
  • Data Deletion Requests: For additional details or manual verification, visit our User Data Deletion Instructions page.

6. Security Measures

All API requests to Meta use industry-standard HTTPS/TLS encryption. We adhere to the Meta Developer Platform Terms and Data Use Checkup guidelines.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in our tools, Meta API versions, or legal requirements. Updated versions will be published to this URL with an updated effective date.
